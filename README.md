
# Сайт доставки еды Star Burger

Это сайт сети ресторанов Star Burger. Здесь можно заказать превосходные бургеры с доставкой на дом.

![скриншот сайта](https://dvmn.org/filer/canonical/1594651635/686/)

Сеть Star Burger объединяет несколько ресторанов, действующих под единой франшизой. У всех ресторанов одинаковое меню и одинаковые цены. Просто выберите блюдо из меню на сайте и укажите место доставки. Мы сами найдём ближайший к вам ресторан, всё приготовим и привезём.

На сайте есть три независимых интерфейса:
1. **Публичная часть** — где клиенты могут выбрать блюда из меню и быстро оформить заказ без регистрации.
2. **Панель менеджера** (`/manager/orders/`) — интерфейс обработки заказов. Менеджер видит поступившие новые заказы, расчет расстояний до ближайших ресторанов, способ оплаты и статус доставки.
3. **Панель администратора** (`/admin/`) — управляет меню ресторанов, категориями товаров, пользователями и кэшем геокодирования.

## Переменные окружения

Проект считывает настройки из файла `.env`, расположенного в корне проекта рядом с `manage.py`.

Создайте файл `.env` и укажите следующие параметры:

| Переменная | Описание | Пример значения |
| :--- | :--- | :--- |
| `SECRET_KEY` | Секретный ключ Django для шифрования сессий и данных. | `django-insecure-0if40nf4nf93n4` |
| `DEBUG` | Флаг отладочного режима (`True` для разработки, `False` для продакшена). | `True` |
| `ALLOWED_HOSTS` | Список хостов/доменов через запятую, с которых разрешен доступ к серверу. | `127.0.0.1,localhost,yourdomain.com` |
| `YANDEX_GEOCODER_API_KEY` | API-ключ Кабинета разработчика Яндекс.Карт для работы геокодирования. | `a1b2c3d4-e5f6-7890-abcd-ef1234567890` |

## Как запустить dev-версию сайта

Для работы сайта в режиме разработки требуется **одновременный запуск бэкенда и фронтенда** в двух разных терминалах.

### 1. Сборка и запуск бэкенда

Скачайте код и перейдите в каталог проекта:
```sh
git clone [https://github.com/devmanorg/star-burger.git](https://github.com/devmanorg/star-burger.git)
cd star-burger

```

Проверьте наличие Python (версии **3.10** или выше):

```sh
python --version

```

Создайте и активируйте виртуальное окружение:

```sh
# Windows
python -m venv venv
.\venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate

```

Установите зависимости:

```sh
pip install -r requirements.txt

```

Настройте файл `.env` в корне проекта (см. раздел [Переменные окружения](https://www.google.com/search?q=%2523%25D0%25BF%25D0%25B5%25D1%2580%25D0%25B5%25D0%25BC%25D0%25B5%25D0%25BD%25D0%25BD%25D1%258B%25D0%25B5-%25D0%25BE%25D0%25BA%25D1%2580%25D1%2583%25D0%25B6%25D0%25B5%25D0%25BD%25D0%25B8%25D1%258F&utm_source=gemini)).

Примените миграции базы данных:

```sh
python manage.py migrate

```

Создайте суперпользователя для доступа в админку (по желанию):

```sh
python manage.py createsuperuser

```

Запустите dev-сервер:

```sh
python manage.py runserver

```

---

### 2. Сборка фронтенда

Откройте **второй терминал** и перейдите в папку проекта.

Проверьте наличие Node.js (рекомендуемая версия **16.16.0**):

```sh
node --version
npm --version

```

Установите JS-зависимости:

```sh
npm ci --dev

```

Запустите Parcel для автоматической сборки фронтенда при изменениях:

```sh
# Linux / macOS
./node_modules/.bin/parcel watch bundles-src/index.js --dist-dir bundles --public-url="./"

# Windows
.\node_modules\.bin\parcel watch bundles-src/index.js --dist-dir bundles --public-url="./"

```

После завершения сборки откройте сайт по адресу [http://127.0.0.1:8000/](https://www.google.com/search?q=http://127.0.0.1:8000/&utm_source=gemini).

## Как запустить prod-версию сайта

1. **Соберите статическую бандл-сборку фронтенда:**
```sh
./node_modules/.bin/parcel build bundles-src/index.js --dist-dir bundles --public-url="./"

```


2. **Соберите статику Django:**
```sh
python manage.py collectstatic

```


3. **Проверьте переменные в `.env`:**
* Установите `DEBUG=False`.
* Укажите уникальный и стойкий `SECRET_KEY`.
* Задайте актуальный список `ALLOWED_HOSTS`.
* Убедитесь, что прописан `YANDEX_GEOCODER_API_KEY`.


4. **Запустите WSGI/ASGI-сервер** (например, Gunicorn или uWSGI):
```sh
gunicorn star_burger.wsgi:application --bind 0.0.0.0:8000

```

## Особенности архитектуры и оптимизации

В проекте выполнен ряд рефакторингов и оптимизаций производительности:

* **Кэширование геоданных (`Geocache`)**: Адреса клиентов и ресторанов геокодируются через API Яндекс.Карт один раз и сохраняются в БД. Повторные запросы к внешнему API не выполняются, расчет расстояний до ресторанов производится локально с помощью `geopy`.
* **Оптимизация ORM-запросов**:
* В панелях управления использованы `annotate()`, `select_related()`, `prefetch_related()` и `values_list()` для предотвращения проблемы N+1 запросов.
* Часто используемые поля для фильтрации и сортировки (`status`, `created_at`, `payment_method`, `availability`) проиндексированы (`db_index=True`).


* **Целостность данных**:
* Поля стоимости и цен зафиксированы типом `DecimalField`.
* Удаление товаров защищено через `on_delete=models.PROTECT`, что предотвращает случайное удаление прошлых заказов из истории при изменении меню.
